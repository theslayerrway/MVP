# MVP — install in Claude Code

How YOU get MVP in your Claude Code (real plugin marketplace):

## Install (one command)
/plugin marketplace add theslayerrway/MVP
/plugin install mvp@theslayerrway/MVP

That's it — the mvp skill is now available in your Claude Code sessions.
Trigger it with: `mvp this: [your idea]`

## What installs
- `mvp` skill — the analyze → premortem → regression → act protocol
- Runs model-agnostic; reads your project files, infers the rest

## Claude Desktop (one-click)
If you're on Claude Desktop, grab the .dxt from the repo releases and double-click it.
See `claude-dxt.md` for the manifest.

## Note
The Claude consumer app (chat) has no public skill store in 2026.
For that, paste the protocol into a Claude Project as the project context.
The skill text is in the repo SKILL.md — copy it into your Project.
