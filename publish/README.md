# MVP

MVP is a methodology that takes a project from idea to a shipped minimum viable product. It runs a fixed protocol — analyze, premortem, regression, act — and checks every plan against a log of known failures before acting.

Install it where you already work.

## Install

| Platform | Command / action |
|----------|------------------|
| Claude Code | `/plugin marketplace add theslayerrway/MVP` then `/plugin install mvp@theslayerrway/MVP` |
| Claude Desktop | download `mvp.dxt` from releases, double-click |
| ChatGPT | open the GPT Store, search "MVP — From Chat to Product" |
| Gemini | open the shared Gem, or paste `gemini-gem.md` into a new Gem |
| Kimi | open the shared assistant, or paste `kimi-assistant.md` |

Each file in this folder is a ready-to-use install for one platform. Pick yours, follow the steps.

## Why model-agnostic

The protocol is plain text. The same instructions drop into any frontend AI. No lock-in.

## Files

- `chatgpt-gpt.md` — GPT Store install
- `claude-plugin.md` — Claude Code marketplace
- `claude-dxt.md` — Claude Desktop extension
- `gemini-gem.md` — Gemini Gem
- `kimi-assistant.md` — Kimi assistant
